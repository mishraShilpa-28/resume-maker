How to save the PDF

Press Save as PDF. In the print window choose Destination: Save as PDF, Paper: A4, Margins: Default, Scale: 100, and turn Headers and footers off. The file name above is filled in for you. The PDF has real, selectable text, so applicant tracking systems can read every word.

Use Word (.docx) when a job portal or agency asks for Word, or for old portals (Taleo, some government and PSU sites). Otherwise send the PDF.
